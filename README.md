# Аналитика программной сетки и спроса аудитории

Набор интерактивных веб-инструментов для программного директора телеканала в Казахстане — сопоставить сетку вещания со спросом аудитории и находить недооценённые зоны роста рейтинга. Подробности и контекст — в [PRD.md](PRD.md).

## Инструменты

- **[Пульс сетки](puls-setki.html)** (Модуль 1) — недельная сетка вещания по получасовым слотам, рейтинг = HUT × доля канала, автоматическая подсветка слабых/сильных слотов, ручной ввод реальных цифр по клику. Пока на демо-данных, сгенерированных по структуре еженедельного отчёта TNS/Kantar.
- **[Спрос и предложение](sprosom-predlozhenie.html)** (Модуль 2+3) — сверка доли эфира под контент разного происхождения с публичным спросом аудитории, жанровые и тайминговые ориентиры, маркировка охвата (эфир/интернет/глобально).

## Формат

Каждый модуль — самостоятельный самодостаточный HTML-файл без сборки и зависимостей, дорабатывается за один разговор без формального ТЗ для разработчиков. Пользовательский ввод хранится локально в браузере (`localStorage`) и не передаётся на сервер.

## Статус

Следующие шаги — Модуль 4 (симулятор перестановок сетки) и подстановка реальных данных из еженедельного отчёта TNS/Kantar в Модуль 1 вместо демо-значений. См. раздел «Roadmap» в [PRD.md](PRD.md).
